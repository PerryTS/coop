Perch application ABI v2 and direct-link optimization
=====================================================

Machine state
-------------
Apple M1 Max, macOS 26.5. The machine was severely contended during these
runs. One-minute load was roughly 149-180, so wall times are directional.

Artifact changes
----------------
- application HTTP ABI: required handle(Buffer): Buffer / Promise<Buffer>
- public application exports: perry_module_init + handle (2 total)
- no ABI-v1, manifestless, string, JSON, or Base64 application fallback
- two-level dynamic dependencies on separate runtime and stdlib providers
- dead stripping enabled at the final application link
